## 🚀 What This Is

A complete template system for **faceless YouTube creators** who want premium visuals without showing their face. Works in **Canva** AND **Affinity Designer**.

**Why faceless?** Because your ideas are the star—not your face.

---

## 📦 What's Inside

| Folder | What You Get |
|--------|--------------|
| `/templates/canva` | Canva-ready templates with step-by-step guides |
| `/templates/affinity` | Affinity Designer templates (.afdesign) |
| `/assets/common` | Brand kit with colors (#E84A00) and fonts |
| `/exports/guides` | PDF guides for Canva ↔ Affinity export |
| `/cheatsheets` | Keyboard shortcuts + tool mapping |
| `/prompts` | AI prompts for faceless content creation |

## ⚡ Quick Start (5 Minutes)

1. **Open** the template folder for your tool
2. **Replace** placeholder text with your script
3. **Export** as MP4/PNG
4. **Post** and grow your channel

---

## 🔄 Canva ↔ Affinity Bridge

All templates are designed to **translate perfectly** between both tools. Use the `/exports/guides/canva-to-affinity-guide.md` file to learn how to move designs between them.
